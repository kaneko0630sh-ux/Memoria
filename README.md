# Memoria — 長期記憶型 AI ロールプレイチャット

ビルド不要のブラウザアプリです（HTML + CSS + JavaScript モジュール）。
APIキーは各端末のブラウザ内（IndexedDB）にだけ保存され、選んだAPIへ直接送信されます。

公開URL: https://kaneko0630sh-ux.github.io/Memoria/

## iPhone で使う
1. 公開URLを Safari で開き、共有ボタン →「ホーム画面に追加」
2. マイページでプロバイダ・APIキー・モデルを入力（「接続テスト」で確認）
3. ホームで「サンプルを読み込む」→ プロットを選んで「トークを始める」

返信が遅いときは、マイページ →「思考」を「オフ」にしてください（DeepSeek は既定で長く考えます）。

## 画面
- **ホーム**: 表紙付きのプロットカード（ランキング・タグ・検索・ブックマーク）
- **プロット詳細**: 表紙・キャラクター・ストーリー・設定集・イントロ →「トークを始める／続きから」
- **トーク**: ナレーションは ≡ 付きの斜体、キャラの台詞は吹き出し。☰ で新しいトーク・再開・トークプロフィール・選択肢・記憶・作者メモ・プラグイン
- **作成（プロット編集）**: プロンプト / 設定集 / スタイル / プラグイン / イントロ / 紹介 / 詳細

## 記憶のしくみ
| 層 | 中身 | 渡し方 |
|---|---|---|
| 現在の状況 | 時刻・場所・その場の人物・所持品 | 毎ターン書き直し・常に渡す |
| 進行度 | 局面と目標・未解決の筋・関係の現在地・演出メモ | 毎ターン書き直し・常に渡す |
| 記憶帳（キャラ別・世界・ユーザー） | 積み重なった事実 | 固定と★5は常に、それ以外は場面に合わせて選択 |
| あらすじ | 直近より古い会話の要約 | 常に渡す（一定量で自動統合） |
| 設定集 | 常時の設定 + キーワード発火のロアブック | 常時分は毎回、キーワード分は会話に出たときだけ |

- 記憶係（別モデル可）が毎ターン、事実の抽出と「次の場面で使う記憶」の選択を行います。裏で動くので返信速度には影響しません。
- 巻き戻すと記憶もその時点に戻ります。記憶パネルで閲覧・編集・固定できます。

## 対応
- プロバイダ: Anthropic (Claude) / OpenAI / OpenRouter / NanoGPT（サブスク限定モード対応） / DeepSeek / Google Gemini / OpenAI互換（カスタムURL） / デモ（APIなし）
- 読み込み: SillyTavern キャラクターカード（PNG・JSON）、ワールド情報（ロアブック）、Memoria のプロット書き出し
- バックアップ: 全データを JSON で書き出し・読み込み

## コードの構成
```
index.html            画面の土台
css/app.css           見た目（部品ごとに章立て）
js/main.js            起動・データ読み込み・形式の移行
js/core/              util（汎用関数）/ db（IndexedDB）/ store（状態とデータ形式）/ hooks（イベント通知）
js/llm/providers.js   プロバイダの登録と呼び出し
js/engine/            parse（出力の解析）/ style（文体・演出）/ lorebook / memory（記憶）/ prompt（組み立て）/ chat（進行）
js/plugins/           registry（プラグインの仕組み）/ dice / diary
js/ui/                dom（部品）/ app（画面切替・アクション）/ blocks（出力の表示）/ views/（各画面）
js/io/porting.js      読み込み・書き出し・サンプル
```
- エンジン層は画面を直接触らず、`core/hooks.js` のイベントで通知します。
- **プロバイダを増やす**: `js/llm/providers.js` の `PROVIDERS` に1件追加
- **文体・演出の選択肢を増やす**: `js/engine/style.js` の `STYLE_GROUPS` に1件追加（エディタとプロンプトに自動で反映）
- **プラグインを作る**: `js/plugins/` にファイルを作って `definePlugin({...})` し、`js/main.js` で読み込む。使えるフック（出力ルール・毎ターンの文脈・見出しブロックの表示・応答後の処理・☰メニュー・設定項目）は `js/plugins/registry.js` の冒頭に説明があります。

### PC で動かす
```bash
npx serve .
```
ES モジュールを使うため、ファイルを直接開くのではなくサーバー経由で開いてください。

## 注意
- iPhone の Safari は、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使い、ときどき「マイページ → バックアップを書き出す」を。
- 共有端末ではAPIキーを保存しないでください。
