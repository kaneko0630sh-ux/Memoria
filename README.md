# Memoria — 長期記憶型 AI ロールプレイチャット

`index.html` 1ファイルだけで動くブラウザアプリです。サーバー不要、ビルド不要。
APIキーは各端末のブラウザ内（IndexedDB）にだけ保存され、選んだAPIへ直接送信されます。

## iPhone で使う

1. `index.html` をどこかに公開する（下記 GitHub Pages が簡単・無料）
2. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動 → 設定タブでプロバイダ・APIキー・モデルを入力
4. チャットタブで「サンプルを読み込む」→ ＋ で新しいチャット

### GitHub Pages で公開する
1. GitHub で新しいリポジトリを作成し、`index.html` をアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

APIキーはページに含まれないので、URLを公開してもキーは漏れません（キーは開いた端末ごとに入力）。

### PC で試す
```bash
npx serve .
```
表示された `http://localhost:3000` を開きます。データは開いたURL（オリジン）ごとに別々に保存されます。

## 記憶のしくみ（ロアブックのキー発火とは別方式）

| 層 | 中身 | 更新タイミング |
|---|---|---|
| 現在の状況 | 時刻・場所・その場の人物・所持品・進行中の目的 | 毎ターン丸ごと書き直し |
| キャラ記憶（1人ずつ） | そのキャラの体験・感情・関係・約束・秘密・「知っていること／知らないこと」 | 毎ターン追加・更新・削除 |
| 世界記憶 | 場所・組織・NPC・出来事 | 毎ターン追加・更新・削除 |
| ユーザー記憶 | あなたについて判明した事実 | 毎ターン追加・更新・削除 |
| あらすじ | 直近の会話より古い部分の要約 | 会話が直近の件数を超えたら順次 |

- **確定したターンだけを記憶**: 新しい発言を送った時点で、それまでのやり取りを確定とみなして事実を抽出します。再生成・スワイプ中の応答は記憶に入りません。
- **一定量を保つ**: 記憶帳ごとに字数の上限があり、超えるとその帳だけを統合・圧縮します。重要度★4〜5は内容を保ち、📌固定した記憶は圧縮・削除されません。
- **常に全部入り**: キーワードで出し入れせず、毎回すべての記憶と現在の状況をAIへ渡します。最新の発言の直前に差し込むので、長い会話でも設定を踏み外しにくくなります。
- **巻き戻しに追従**: 「ここから下を削除」で巻き戻すと、記憶もその時点に戻ります（直近15回分のスナップショット）。
- **透明性**: 記憶パネルで全記憶の閲覧・編集・固定・手動追加、送信プロンプトの内訳と全文、処理ログを確認できます。

## 費用の目安
1ターンにつき「応答1回＋記憶抽出1回」、数ターンに1回「あらすじ要約」が走ります。
設定 → 記憶エンジン で記憶処理だけ安いモデル（例: `claude-haiku-4-5`）にすると費用を抑えられます。

## 対応
- プロバイダ: Anthropic (Claude) / OpenAI / OpenRouter / NanoGPT（サブスク限定モード対応） / Google Gemini / OpenAI互換（カスタムURL） / デモ（APIなし）
- 読み込み: SillyTavern キャラクターカード（PNG・JSON V1/V2）、SillyTavern ワールド情報（JSON → 世界設定に常時展開）
- バックアップ: 全データを JSON で書き出し・読み込み

## 注意
- iPhone の Safari は、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使い、ときどき「設定 → バックアップを書き出す」を。
- 共有端末ではAPIキーを保存しないでください。
