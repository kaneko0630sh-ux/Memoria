# Memoria プロット形式（memoria-story v3）

Memoria は、プロット（世界観・キャラクター・導入をまとめた物語）を選んでAIとロールプレイするアプリです。
このファイルの形式で作った JSON は、Memoria の「作成」タブから読み込めます（ファイル、または貼り付け）。
各項目に**何をどう書くと面白くなるか**は `plot-writing-guide.md` にあります。

## 全体の形

```json
{
  "app": "memoria-story",
  "version": 3,
  "story": {
    "title": "",
    "description": "",
    "tags": [],
    "prompt": "",
    "userRole": "",
    "guide": "",
    "world": "",
    "chars": [
      { "name": "", "profile": "", "personality": "", "speech": "", "note": "" }
    ],
    "examples": [
      { "char": "キャラ名", "situation": "", "reply": "" }
    ],
    "profiles": [
      { "name": "", "desc": "" }
    ],
    "lore": [
      { "title": "", "keys": [], "content": "", "always": false }
    ],
    "style": {},
    "plugins": {},
    "opening": "",
    "creatorNote": ""
  }
}
```

- 文字列の中の改行は `\n`。JSON として厳密に正しいこと（コメント・末尾カンマは不可）。
- 使わない項目は空文字 `""` か空配列 `[]` でよい（省略しても読み込める）。
- 画像（表紙・キャラ画像）は JSON には入れない。読み込んだ後にアプリで追加する。

## 置き換えの記号
- `{{user}}` … ユーザー。トーク時に、ユーザーが選んだトークプロフィール（ペルソナ）の名前に置き換わる。**ユーザーのことは必ずこう書く。** ナレーションや地の文で「あなた」と書かない（キャラの台詞の中での呼び方は、そのキャラの口調に従ってよい）。
- `{{char}}` … キャラクター名（複数なら「、」区切り）。基本は名前を直接書けばよい。

## 各項目

| 項目 | 画面での名前 | 中身 | 目安 |
|---|---|---|---|
| `title` | 題名 | プロットの題名 | **30字以内**・必須 |
| `description` | 紹介文 | ホームのカードに出る紹介。一場面を切り取った引きのある文 | 120字以内 |
| `tags` | タグ | ジャンルや要素 | 3〜6個 |
| `prompt` | 説明（プロンプト） | ジャンル・舞台・{{user}}の立場と欠かせない理由・キャラとの関係・中心の問い・障害・時間制限 | 300〜1000字 |
| `userRole` | あなたの役 | この物語での{{user}}の役柄・立場・キャラとの関係。外見や性格はユーザーが自分で決めるので、決めすぎない | 50〜200字 |
| `guide` | AIへの追加指示 | 演出の指示書（本文では言及されない）。見出し付きで「進め方／物語の流れ／出来事の種（12個前後）／秘密と伏線／避けること」 | 500〜1500字 |
| `world` | 常に参照する設定 | 世界観の核。毎回AIに渡されるので、毎場面に効く基本ルール・舞台・勢力だけを短く | 200〜1200字 |
| `chars` | キャラクター | 下記。**最低1人・最大10人**。主要キャラは1〜3人がおすすめ | |
| `examples` | 状況例 | 「こんな状況ならこう返す」の例。口調を安定させる。違う感情が出る状況を選ぶ | 主要キャラごとに2〜3個 |
| `profiles` | トークプロフィール | ユーザーが選べる、この物語用の主人公案（任意）。名前が決まった主人公がいる物語で使う | 0〜5個 |
| `lore` | キーワード設定（ロアブック） | 会話にキーワードが出たときだけAIに渡される設定 | 必要な分だけ（5〜15個が目安） |
| `style` | スタイル | 文体・演出・進行の選択（下の表） | |
| `plugins` | プラグイン | 追加機能（下記） | |
| `opening` | イントロ | トーク開始時に最初に表示される場面（下記の書式） | 300〜800字 |
| `creatorNote` | クリエイターコメント | 遊び方のヒントなど（任意） | |

`title` + `prompt` + `userRole` + `guide` + 全キャラの項目の合計は、6000字以内が目安です（`world`・`lore`・`examples`・`opening` は含まない）。主要キャラ1人あたり800〜1500字くらいが濃さと軽さのバランスがよいです。

### キャラクター（`chars` の1人分）
| 項目 | 中身 |
|---|---|
| `name` | 名前（**20字以内**・必須）。会話で呼ばれる形。短いほど良い |
| `profile` | プロフィール: 年齢・外見（目立つ特徴）・立場・経歴／生活（仕事や学校・日課・趣味やこだわりを固有名詞まで）／{{user}}との関係の現在地 |
| `personality` | 性格: 核／表の顔と裏の顔／欲しいもの・怖いもの／矛盾（「〇〇なのに△△」）／長所と短所 |
| `speech` | 口調・話し方: 一人称、{{user}}の呼び方、他キャラの呼び方、語尾、口癖／気持ちごとの台詞例（普段・照れ・怒り・不安や嫉妬・弱ったとき・本気） |
| `note` | 補足・演技指示: 反応の型（「〇〇されると△△する」を5〜8個）／関係の段階と各段階の態度、進むきっかけ／秘密と明かす条件／NG |

キャラを「ツンデレ」「クール」のような型の名前で済ませず、具体的な行動・台詞・反応の型で書いてください（詳しくは `plot-writing-guide.md`）。

### 状況例（`examples` の1件分）
| 項目 | 中身 |
|---|---|
| `char` | どのキャラの例か（`chars` の `name` と同じ文字列） |
| `situation` | 状況（例: `{{user}}が約束に遅れてきた`） |
| `reply` | そのキャラの反応。イントロのキャラブロックと同じ書式（`*動作*` の行と台詞の行）。見出し【】は付けない |

### キーワード設定（`lore` の1件分）
| 項目 | 中身 |
|---|---|
| `title` | 項目名 |
| `keys` | キーワードの配列。会話の直近数件にどれかが含まれると、この項目がAIに渡される。固有名詞・別名・表記揺れ（漢字/かな/カナ）を入れる |
| `content` | 内容。これ単体で意味が通るように書く（100〜300字） |
| `always` | `true` にするとキーワードに関係なく毎回渡す。基本は `false`（毎回必要なものは `world` に書く） |

向いているもの: 脇役・組織・地名・建物・アイテム・魔法や技術の仕組み・歴史的事件・伏線の真相（「まだ明かさない」「〇〇したら明かす」と書き添える）など。

- **脇役**（ときどき登場する人物）は `chars` ではなくここに入れる。キーワードは名前・あだ名・肩書き。内容は外見・立場・性格・口調（一人称など）・{{user}}や主要キャラとの関わり。
- 1つの項目に1つの話題。長くなるものは「場所: 灯台」「場所: 第三埠頭」のように分ける。
- `keys` は短い語にする（文ではなく単語）。略称・読み・カタカナ表記も入れると拾われやすい。

### トークプロフィール（`profiles` の1件分）
| 項目 | 中身 |
|---|---|
| `name` | 名前（20字以内） |
| `desc` | 外見・立場・キャラとの関係など |

ユーザーは自分で保存したプロフィールも使えるので、必須ではありません。

## イントロ（`opening`）の書式
Memoria の出力と同じ「見出しブロック」形式で書きます。見出しは行頭に単独で置きます。

```
【ナレーション】
情景や状況の描写。段落ごとに改行する
【キャラ名】
*動作・表情・内心（行全体を * で囲む）*
台詞（「」は付けない）
*動作*
台詞
【別のキャラ名】
*動作*
台詞
```

- `【ナレーション】` … 地の文。場面・空気・出来事。
- `【キャラ名】` … `chars` の `name` と同じ名前。`*…*` の行は動作・表情・内心、それ以外の行は台詞（かぎかっこなし）。
- {{user}}の台詞・行動・内心は書かない。キャラが{{user}}に働きかけ、{{user}}が返したくなるところで終える。
- 文字列としては改行を `\n` で表す。

## スタイル（`style`）
値は下の「値」を使います（日本語の表示名でも読み込めます）。書かなかった項目は既定値になります。

| キー | 意味 | 値（表示名） | 既定 |
|---|---|---|---|
| `difficulty` | 難易度 | `easy`（簡単）/ `normal`（普通）/ `hard`（難しい）/ `extreme`（極限） | `normal` |
| `pace` | 展開速度 | `fast`（速い）/ `natural`（自然）/ `slow`（遅い） | `natural` |
| `pov` | ナレーション視点 | `1st`（一人称）/ `2nd`（二人称: ナレーションが{{user}}を「あなた」と呼ぶ）/ `3rd`（三人称） | `3rd` |
| `tense` | 時制 | `past`（過去形）/ `present`（現在形） | `past` |
| `length` | 応答の長さ | `one`（一言: 描写1つ＋台詞1つでチャットのように返す）/ `short`（200〜400字）/ `medium`（400〜800字）/ `long`（800〜1500字）/ `auto`（自動） | `auto` |
| `expr` | 表現方式 | `dialog`（会話多め）/ `basic`（基本）/ `action`（行動多め） | `basic` |
| `mood` | 雰囲気（配列・最大2つ） | `romance`（ロマンス）/ `iyashi`（癒し）/ `serious`（シリアス）/ `yandere`（ヤンデレ）/ `fantasy`（ファンタジー）/ `action`（アクション）/ `mystery`（ミステリー）/ `horror`（ホラー） | `[]` |
| `prose` | 文章スタイル | `real`（等身大リアリズム: 短文と具体描写、本音が地の文ににじむ）/ `romance`（恋愛心理小説）/ `hardboiled`（ハードボイルド）/ `nocturne`（夜想文学: 静かで詩的）/ `seishun`（温かな青春物語）/ `action`（アクション）/ `fantasy`（王道ファンタジー）/ `lightnovel`（ライトノベル: テンポのよい掛け合い）/ `horror`（心理ホラー）/ `none`（設定しない） | `real` |
| `choices` | 選択肢の提案 | `true` / `false`（ユーザーの番に行動の候補を3つ出す） | `false` |
| `infoBg` | 背景のインフォボックス | `on` / `off`（応答の最後に日時・場所・天気） | `off` |
| `infoChar` | キャラのインフォボックス | `on` / `off`（登場キャラの服装・感情・{{user}}への印象） | `off` |

例: `"style": { "mood": ["mystery", "romance"], "pace": "slow", "prose": "nocturne" }`

## プラグイン（`plugins`）
使うものだけ `"on": true` で書きます。

| ID | 名前 | 設定 | 向いている物語 |
|---|---|---|---|
| `dice` | ダイスイベント | `"sides"`: `"6"` / `"20"` / `"100"`（既定 `"20"`） | 戦闘・冒険・TRPG風。山場でユーザーがダイスを振って成否が決まる |
| `diary` | キャラクターの日記 | `"every"`: 日記を書く間隔（ターン数・3〜50、既定 8） | 恋愛・日常・長編。キャラが自分視点の日記を残す |
| `status` | ステータス管理 | 下記 | 冒険・戦闘・サバイバル・生活もの。所持金・持ち物・装備・スキル・体力などをアプリが管理する |

例: `"plugins": { "dice": { "on": true, "sides": "20" } }`

### ステータス管理（`status`）の設定
会話の中の売買・入手・消費・負傷はアプリが自動で記録し、AIは記録に合わせて描写します。戦利品の中身・レア度・鑑定の査定額はアプリがサイコロで決めます。
書かなかった項目は、`preset`（ひな型）の値になります。

| キー | 中身 | 例 |
|---|---|---|
| `preset` | ひな型: `adventurer`（冒険者・生活ファンタジー）／`salvage`（荒廃SF・サルベージ）／`simple` | `"salvage"` |
| `currency` | 通貨の単位 | `"G"`、`"C"` |
| `money` | 最初の所持金（数値） | `120` |
| `items` | 最初の持ち物。1行に1つ「名前×数（種類）」 | `"回復薬×2（消耗品）\n松明×1（消耗品）"` |
| `equip` | 最初の装備。1行に1つ「枠: 名前」 | `"武器: ショートソード\n防具: 革の鎧"` |
| `skills` | 最初のスキル。1行に1つ「名前: ランク」 | `"剣術: 初級\n採集: 初級"` |
| `gauges` | ゲージ。「名前:最大」か「名前:今/最大」をカンマ区切り | `"HP:50,MP:20,汚染度:0/100"` |
| `cats` | 持ち物の種類（カンマ区切り） | `"消耗品,素材,装備品,貴重品,重要"` |
| `slots` | 装備の枠（カンマ区切り） | `"武器,防具,装飾品"` |
| `prices` | 相場表。1行に1つ「品目 値段」。AIの値段の目安になる | `"パン 3G\n宿代（1泊）50G"` |
| `life` | 生活（拠点・家賃・建設・依頼・日付）: `"on"`／`"off"` | `"on"` |
| `explore` | 探索（現在地・戦利品・鑑定・評判）: `"on"`／`"off"` | `"on"` |
| `factions` | 評判を記録する勢力（カンマ区切り） | `"冒険者ギルド,商人組合"` |
| `carry` | 積載の上限（0で使わない） | `20` |
| `weights` | 種類ごとの重さ「種類:重さ」（カンマ区切り） | `"遺品:2,部品:1,弾薬・電池:0"` |
| `relic` | 未鑑定品の呼び名 | `"未鑑定の遺品"` |
| `legend` | 最高ランクの呼び名 | `"遺物級"` |
| `materials` / `consumables` | 戦利品で出る素材／消耗品の候補（カンマ区切り） | `"電子基板,銅線の束"` |

例: `"status": { "on": true, "preset": "adventurer", "money": 50, "items": "古びた短剣×1（装備品）\n回復薬×1（消耗品）", "prices": "パン 3G\n宿代（1泊）50G\n回復薬 30G" }`

物語に合わせて、`items`・`equip`・`skills`・`prices`・`factions` はできるだけ具体的に書く（相場表があると、AIの値段がぶれない）。

## アプリ側で自動的に行われること（プロットに書かなくてよいもの）
- 出力形式（【ナレーション】/【キャラ名】のブロック）の指示と、文体の細かい指示
- 会話の記憶（毎ターン事実を積み上げ、場面に合う記憶を選んで渡す）と、あらすじの要約
- 「現在の状況」（時刻・場所・その場の人物・所持品）の管理
