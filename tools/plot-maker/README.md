# Memoria プロット作成ツール

Claude や ChatGPT に短いヒアリングをしてもらい、世界観・キャラクター・イントロ・設定集（ロアブック）まで入った
Memoria のプロットを作ってもらうためのセットです。アプリの外（Claude / ChatGPT の「プロジェクト」）で動かすので、
大きなモデルでじっくり作れます。

## 入っているもの
| ファイル | 使い方 |
|---|---|
| [`instructions.md`](instructions.md) | プロジェクトの「指示（カスタム指示）」に**中身を貼り付ける** |
| [`memoria-plot-format.md`](memoria-plot-format.md) | プロジェクトのファイル（ナレッジ）に**アップロード** |
| [`example.memoria.json`](example.memoria.json) | プロジェクトのファイル（ナレッジ）に**アップロード**（完成例） |

## 準備（最初に1回。PC からの方が楽です）

### Claude（claude.ai）
1. 左のメニュー「プロジェクト」→「プロジェクトを作成」（名前は例:「Memoria プロット作成」）
2. 「指示」（Instructions）を開き、`instructions.md` の中身をすべて貼り付けて保存
3. 「ファイル」（プロジェクトナレッジ）に `memoria-plot-format.md` と `example.memoria.json` を追加
4. （任意）設定 →「機能」で「コード実行とファイル作成」をオンにすると、`.memoria.json` ファイルとしても受け取れます

### ChatGPT
- **プロジェクトで使う**: サイドバー「プロジェクト」→ 新しいプロジェクト → プロジェクトの設定で「指示」に `instructions.md` の中身を貼り付け、「ファイルを追加」で2つのファイルを追加
- **GPT（マイGPT）で使う**: 「GPTを作成」→「構成」→「指示」に貼り付け、「知識」に2つのファイルをアップロード。「コードインタープリターとデータ分析」をオンにするとファイルでも受け取れます

`.json` がアップロードできない場合は、拡張子を `.txt` に変えてから追加してください。

## 使い方
1. プロジェクト内で新しいチャットを開き、「プロットを作りたい」と送る（「幼馴染と再会する切ない恋愛もの」のように、最初から一言添えても OK）
2. 5つほどの質問に答える（番号だけ・「おまかせ」でも OK）
3. 設計メモが出るので「OK」か、直したいところを一言
4. JSON（とファイル）が出てきたら、Memoria に読み込む

## Memoria への読み込み
- **iPhone**: コードブロックのコピーボタンで JSON をコピー → Memoria の「作成」タブ →「テキストを貼り付けて読み込む」に貼り付け →「読み込む」
- **ファイルで受け取った場合**: 「作成」タブ →「ファイルから読み込む」で `.memoria.json` を選ぶ

読み込んだら「作成」タブの一覧からプロットを開き、表紙やキャラクターの画像を追加してください。
修正したくなったらそのままチャットで頼めば、直した JSON を全文出し直してくれます（読み込むと別のプロットとして追加されます）。

## 形式について
JSON の形式は [`memoria-plot-format.md`](memoria-plot-format.md) の通りです。Memoria の「このプロットを書き出す」で作ったファイルも同じ形式なので、
自作のプロットを Claude / ChatGPT に渡して「これを元に続編を作って」のような使い方もできます。
