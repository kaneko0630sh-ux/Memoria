# Memoria プロットの書き方ガイド

ロールプレイが面白くなるかどうかは、AIに渡す材料の具体性でほぼ決まります。
設定が「明るい」「素直になれない」程度だと、AIはよくある型で埋めるしかなく、どのキャラも同じ反応になって展開も予想どおりになります。
このガイドは、JSON の各項目に**何をどう書くか**をまとめたものです（形式そのものは `memoria-plot-format.md`）。

---

## 1. 濃いキャラクター

### 原則
- **形容詞より行動**: 「優しい」ではなく「〇〇のとき△△する」と書く。
- **型の名前を使わない**: 「ツンデレ」「クール」「ヤンデレ」と書くと、AIは決まり文句の型を演じる。その型の中身を、そのキャラだけの具体的な行動に分解して書く。
- **固有名詞まで具体的に**: 「甘いものが好き」ではなく「コンビニの新作スイーツを毎週チェックして、スマホのメモに辛口レビューをつけている」。具体物はそのまま会話の小道具になる。
- **本心は隠し方と漏れ方まで書く**: 「本当は{{user}}が好き」とだけ書くと、AIは地の文で毎回それを説明してしまう。本心は note に書き、どの反応の型で漏れるか、どうなったら口に出すかを書く。

### 項目ごとの中身
| 項目 | 書くこと |
|---|---|
| `profile` | 年齢・外見（目立つ特徴を1つ）・立場・経歴／**生活**（仕事や学校、日課、趣味やこだわりを固有名詞まで）／{{user}}との関係の現在地 |
| `personality` | 核になる性質／**表の顔と裏の顔**／**欲しいもの**（{{user}}と無関係な人生の目的も）と**怖いもの**／**矛盾**（「〇〇なのに△△」）／長所と短所 |
| `speech` | 一人称、{{user}}の呼び方、他キャラの呼び方、語尾、口癖／**気持ちごとの台詞例**（普段・照れ・怒り・不安や嫉妬・弱ったとき・本気のとき。各1行） |
| `note` | **反応の型**（「〇〇されると△△する」を5〜8個）／**関係の段階**（例: 警戒→信頼→好意）と各段階の態度、段階が進むきっかけ／**秘密**と明かす条件／NG（絶対にしないこと） |
| `examples` | 主要キャラ1人につき2〜3個。**違う感情が出る状況**を選ぶ（照れる・怒る・弱るなど） |

### 反応の型の例
- 図星を突かれると、食べ物の話にそらす
- 嫉妬すると、急に敬語になる
- 褒められると3秒黙ってから「……で？」と返す
- 本気で怒ると、逆に声が小さくなる
- 不安なときほど、どうでもいい冗談が増える

### 脇役
lore の項目に、外見・立場・口調に加えて「欲しいもの」と「反応の型」を1つずつ書く。それだけで、登場したときに生きた人物になる。

## 2. 物語のエンジン（`prompt` に書く）
`prompt` には、物語を動かし続ける仕掛けを必ず入れる。
- **ジャンルと舞台**
- **{{user}}の立場と、欠かせない理由**: {{user}}だけが持つ鍵・秘密・能力・立場。{{user}}が物語の中心にいる感覚が出る
- **キャラとの関係**
- **中心の問い**: 遊んでいる間ずっと気になり続けること（例: 彼女はなぜ嘘をつくのか／師匠はどこへ消えたのか）
- **障害**: 関係や目的を邪魔するもの（ライバル、立場、過去、規則、距離）
- **時間制限**: {{user}}が何もしなくても起きること（引っ越し、締め切り、祭り、期限）

---

## 3. AIへの追加指示（`guide`）
`guide` は毎回AIに渡され、本文には出ない「演出の指示書」です。次の見出しで書く。

```
停滞したら「出来事の種」から今の流れに合うものを1つ選んで起こす。{{user}}の選択は奪わない。同じ種は二度使わない。
## 進め方
（ペース、関係の進め方、何をゆっくり・何を早く）
## 物語の流れ（目安）
序盤: …／中盤: …／山場: …
## 出来事の種
- [序盤] 出来事 → 何が変わるか
- …
## 秘密と伏線
（何をいつ・どうなったら明かすか）
## 避けること
（NG の展開・描写）
```

### 出来事の種
12個前後を、次の6種類から偏りなく選ぶ。1行ずつ、**具体的な出来事**と**それで何が変わるか**を書く。
| 種類 | 例 |
|---|---|
| 日常の小事件 | 停電で店に二人きりになる → 普段しない話をする |
| 関係が揺れる | {{user}}が他の人と親しげにしているのを見る → 反応の型の「嫉妬」が出る |
| 外からの割り込み | 元同僚から突然の連絡が来る → 隠していた過去の一端が見える |
| 秘密に近づく | 古い写真の裏に日付と名前 → 中心の問いに一歩近づく |
| 選択を迫る | 助ければ秘密がばれる状況 → {{user}}に決めさせる |
| ご褒美の場面 | 手作りの弁当が完璧にうまくいく → 甘い・笑える・熱い一幕 |

悪い例: 「何か事件が起きる」「関係が進展する」（抽象的で、AIが使えない）

## 4. イントロ（`opening`）
- **出来事の最中から始める**: 説明から入らない。すでに何かが起きている場面に{{user}}を放り込む。
- **五感の具体的な手がかり**を1〜2つ（音・匂い・光・手触り）。
- キャラの**欲しいもの**か**反応の型**が1つ見えるようにする。
- **本心を地の文で説明しない**: 「けれど本当は〜」「〜が滲んでいた」「言葉とは裏腹に〜」は使わない。気持ちは動作と台詞の具体的な細部1つで匂わせる。
- **引っかかりで終える**: 答えずにいられない問い、途中で止めた動作、新しい事実のどれか。
- {{user}}の台詞・行動・内心は書かない。

---

## 5. 世界観とロアブック
- `world` は毎回渡されるので、毎場面に効く核だけを短く。細部は lore へ。
- 場所の lore には、音・匂い・光などの手がかりを1つ入れる（描写が具体的になる）。
- 伏線の真相を lore に入れるときは「まだ明かさない」「〇〇したら明かす」と書き添える。

---

## 6. 自己点検（出力前に必ず全部確認する）
- [ ] 主要キャラ全員に、表と裏・欲しいもの・怖いもの・矛盾・反応の型5つ以上・気持ちごとの台詞例・生活・関係の段階・秘密がある
- [ ] キャラ設定に「ツンデレ」「クール」などの型の名前だけで済ませた箇所がない
- [ ] 状況例（examples）は主要キャラごとに2〜3個で、違う感情が出る状況になっている
- [ ] `prompt` に、中心の問い・{{user}}が欠かせない理由・障害・時間制限がある
- [ ] `guide` に出来事の種が10個以上あり、6種類が偏っていない。どれも具体的で、何が変わるかが書いてある
- [ ] イントロが出来事の最中から始まり、引っかかりで終わる。本心の説明がない
- [ ] ユーザーは `{{user}}` と書き、地の文で「あなた」と書いていない
- [ ] ヒアリングで決まったことが、すべてどこかの項目に入っている
- [ ] JSON が正しい形になっている
